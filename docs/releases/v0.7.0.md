# 司南 Nanpad 0.7.0

本版让浏览器插件读取你主动选择的网页账号表单，经插件与桌面两次核对后，保存到本机主密码库。

- Chrome / Edge 插件打开时读取当前页可见表单，支持多个候选账号、手工修改、密码遮挡和主动重新读取。
- 桌面「设置 → 浏览器插件」提供一次性配对码、连接状态和断开全部插件入口。配对码 5 分钟有效，使用一次后失效。
- 账号密码通过认证的本机连接发送，不放进跨应用 URL，不经云端转发。桌面再次核对后加密保存，可直接关联已有注册邮箱。
- 待确认账号仅在内存中保留，最多 10 条，每条 5 分钟；锁库、撤销连接或退出会清除。插件显示已送达不等于已经保存。
- 保留「仅记录站点并打开司南」，供稍后手填账号。插件不后台监听登录，不读取浏览器密码库、Cookie 或历史记录。

完整步骤见 [浏览器插件教程](https://github.com/Songwo/nanpad/blob/main/docs/BROWSER-EXTENSION.md)。本版安装包命名为 `Nanpad-0.7.0-setup.exe`，扩展包命名为 `Nanpad-0.7.0-browser-extension.zip`；可用下载以 [GitHub Releases](https://github.com/Songwo/nanpad/releases) 为准。

## 使用边界

桌面端和扩展需升级到 0.7.0，再在解锁状态下配对。锁库、桌面退出或浏览器会话结束后需要重新配对；扩展未上架商店，需要从下载包解压加载。Windows 安装包未做代码签名，下载后应核对 Release 提供的 SHA256 文件。

采集仅作用于当前页顶层文档及开放 Shadow DOM，不读取 iframe 或封闭 Shadow DOM。通行密钥、第三方 OAuth 或已经跳转、清空的表单不能还原成密码记录；识别不准确时可以手动修改，插件不自动填充、不更新已有账号。

凭据连接只监听 `127.0.0.1:47832`，使用配对令牌和扩展来源校验。本机 HTTP 不是 TLS 加密通道，不能防御已控制本机或浏览器的恶意程序；HTTP 网站本身的登录通信也不因此得到加密。名称、标签和普通说明仍是明文元信息，账号密码写入主密码库，不进入自动资产索引或模型上下文。
