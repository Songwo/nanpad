# 司南 Nanpad 0.2.1

本版修复 AI 订阅的快速登录入口，补充手动回调与分类额度展示，并支持个人头像和资产图片。

## 登录与用量

- 「AI 订阅 → 添加资产」默认打开快速登录，可选择 OpenAI / ChatGPT、Anthropic / Claude、xAI / Grok、Google / Gemini。成功授权自动关联订阅并查询用量，同一账号重复授权不会重复新增资产。
- 浏览器未自动返回时，可粘贴本次登录的完整回调链接完成授权；Claude 也保留 `code#state` 方式。回调会校验地址与本次授权状态，过期或取消后需要重新登录。
- 用量按来源和分类窗口显示，提供的字段包括已用比例、已用或剩余数量、总额度、模型、重置时间与查询时间。接口未提供的字段不推算为零。
- 登录失效、权限拒绝、请求过频与网络失败分别显示错误。用量查询失败保留成功授权和上次查询结果，并提示数据已过期。

## 界面与图片

- 下拉菜单统一应用浅色、深色主题，服务商选项同时显示额度来源。
- 「设置 → 个人资料」支持上传、更换或移除头像；资产新增和编辑表单支持自定义图片，已授权的 AI 订阅也可编辑图片。
- 图片仅从本地选择，支持 PNG、JPEG、WebP，单张不超过 8 MiB。原图最长边不超过 8192 像素、总像素不超过 2400 万；头像缩至最长边 256 像素，资产图缩至 512 像素，重编码为 PNG 后保存，每张不超过 1 MiB。图片处理和存储在本机完成。

## 安装与升级

下载 `Nanpad-0.2.1-setup.exe`，运行安装向导。适用于 Windows x64，校验值见 `SHA256SUMS.txt`。当前安装包未签名。升级前备份数据目录，已有资产、资料与主密码继续使用，无需删除数据重新设置。

## 授权范围

| 服务商 | 当前查询范围 |
| --- | --- |
| OpenAI / ChatGPT | Codex 主要及次要窗口、代码审查和接口返回的附加额度、积分 |
| Anthropic / Claude | Claude OAuth 返回的共享窗口及模型用量 |
| xAI / Grok | Grok CLI 周额度、产品额度及月度账单 |
| Google / Gemini | Gemini CLI / Code Assist 模型额度及接口返回的积分 |

这些范围不等于四家网页订阅的全部功能权益，实际可查数据取决于账号资格与上游接口。Gemini 需要已开通 Code Assist 且能返回项目。详情中的「查看官网权益」可打开服务商网页核对；授权套餐名也以接口返回为准。

OAuth 用于账号与额度查询，问答仍需配置独立的 OpenAI 兼容 API Key。令牌有效期、额度重置时间和订阅到期日不会互相推算。真实登录需要账号持有人在服务商网页完成，自动化协议测试不能证明所有私人账号或地区均可用。
