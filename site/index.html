02 / 图文资料

把经验留在资产旁

从「＋」批量导入 Markdown，或在任意页面拖入文件。按目录定位章节、查看阅读进度，编辑时再展开工具。网页可见正文也能确认后保存，随时关联资产。

03 / 真实用量

看清流量与 Token

用图表查看流量、API Token 与订阅额度；读取支持客户端的本机用量日志。采集后更新统计，切页复用缓存；今日明细和小额用量标记保留真实数值，不把缺失数据伪装为零。

04 / 账号与密钥

账号与说明，放在一起

从 Chrome / Edge 导出的 CSV 快速迁入，也能导回浏览器。同站多账号分别保留；登录页自动建议，选中后填写。点击账号直接查看、就地解锁，使用说明随时关联。

让 AI 找到资料之间的联系

反馈与建议 ↗

开始之前，你可能想知道

能统计电脑上所有 AI 的 Token 吗？

本机采集支持 Codex、Claude Code、Grok Build 和 Gemini CLI 中可读取的用量日志，默认开启，无需解锁密钥库，也可手动关闭。未保存日志的网页或客户端无法据此取得精确 Token；没有日志、权限不足和确实没有用量会分别提示。

AI 会直接修改我的资料和密码吗？

开启本次修改建议后，AI 先展示依据和修改前后内容，由你逐项确认。标题改名无需正文许可，正文局部替换需本次授权；缺少权限时可在回答下方允许并继续。账号只支持名称和标签，密码等凭据在本机编辑；资料已变化或建议过期时需重新生成。

以后可以在软件里直接更新吗？

1.4.0 起，在「设置 → 关于」检查并下载新版本，校验完成后点击「重启并安装」。旧版需先安装一次新版，已有资料继续保留。

免费吗？支持什么系统？

知屿是开源项目。目前提供 Windows x64 安装包；macOS 和 Linux 尚未提供经过验证的正式安装包。

数据会上传吗？

资产、文档与用量历史默认保存在本机。启用图床会上传所选图片；连接邮箱、面板或 AI 服务会请求相应服务。使用远端 AI 问答时，相关上下文会发送给你配置的模型。请阅读安全说明。

ChatGPT / Claude 订阅等于 API Token 用量吗？

不等于。订阅账号记录接口能提供的额度快照；API 用量采集依赖组织查询权限。网页订阅不提供的数据不会被估算成精确 Token。

安装时为什么会有系统提示？

目前 Windows 安装包没有代码签名。请从本仓库 Releases 下载，并对照随版本提供的 SHA256 校验文件。升级前建议按安全文档备份。

在哪里开始使用？

下载后确认工作区名称并创建主密码，再添加第一项资产；无需注册。详见 使用教程 与 安全与备份。
