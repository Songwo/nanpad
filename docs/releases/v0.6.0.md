# 司南 Nanpad 0.6.0

本版改善邮件正文排版、头像和加载布局，并补齐真实 Agent 查询邮箱分组与账号归属的链路。

- HTML 邮件在本机净化后展示静态排版；纯文本支持 Markdown / GFM 的标题、列表、表格、引用与代码块，可切换「原文」查看解析后的纯文本。
- 正文外部图片默认拦截，可点击「加载本封图片」逐封加载；切换或重新读取邮件后许可失效。符合限制的 CID 内嵌图片在本机展示。
- 邮箱列表与阅读器提供账号头像及分组编辑入口，正文中的发件人头像支持本地上传，每个邮箱最多保存 32 个；不自动向外部头像服务查询邮箱地址。
- 邮件列表和正文提供骨架占位、未读与选中状态、短暂过渡及窄窗口布局，尊重系统减少动态效果设置。
- 邮箱首页支持分组名称搜索；Agent 可查询全部本地分组、空组、未分组及各组账号，区分邮箱、别名和演示记录。

详细操作见 [邮件工作台教程](https://github.com/Songwo/nanpad/blob/main/docs/MAIL-WORKSPACE.md)。本版安装包命名为 `Nanpad-0.6.0-setup.exe`，扩展包命名为 `Nanpad-0.6.0-browser-extension.zip`；可用下载以 [GitHub Releases](https://github.com/Songwo/nanpad/releases) 为准。

## 使用边界

本地邮箱收纳组与服务器的 IMAP 收件箱、已发送等目录是两套信息。分组查询不需要实时邮箱许可，但分组名称和邮箱地址会作为元信息发送给配置的模型；密码、邮件正文、草稿及头像不会进入工具结果。Agent 不执行自动发信。

远程图片加载可能向图片服务器泄露 IP 地址、阅读时间及 URL 中的跟踪标识，隐藏图片不能撤回已发出的请求。自定义发件人头像和地址对应关系保存在明文资产文件中，随资产导出，不属于加密凭据。邮件 HTML 仅保留有限排版，复杂营销邮件不保证还原原网页效果。

收发信仍通过密码或客户端授权码连接 IMAP / SMTP，不支持仅允许邮件 OAuth 的账号。保留发送前确认、加密草稿及不确定结果不自动重试；不提供邮件删除、联系人同步或后台完整缓存。转发不自动携带原附件，是否保存到服务器已发送文件夹取决于服务商行为。AI 服务网页登录授权与邮箱邮件授权是不同权限。

真实私人邮箱最终投递及完整 NSIS 安装、升级、卸载流程仍需单独验收；隔离测试不向真实收件人发送邮件。Windows 安装包未做代码签名，下载后应核对 Release 提供的 SHA256 文件。服务商网页套餐权益仍以各接口实际返回为准。
