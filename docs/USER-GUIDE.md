# 使用教程

## 安装与升级

从仓库 Releases 下载 Windows x64 安装包。安装后打开司南，新用户设置姓名和至少 10 位主密码；升级用户输入原主密码完成资料设置。不要删除数据目录来解决启动问题，先备份再排查。

在「设置 → 个人资料」修改名字；在「设置 → 密钥库」修改主密码。修改主密码需要原密码。关闭窗口默认进入托盘，托盘菜单可以重新打开、锁库或退出。

## 添加主机

1. 进入主机分类，点击新增，填写名称、地址、端口和用户名。
2. 根据服务器配置选择密码、私钥或 SSH Agent。凭据保存前需要解锁密钥库。
3. 测试连接并保存，然后刷新实际指标。连接失败时核对地址、端口、防火墙和登录权限。
4. 在详情中打开 SSH 终端，或查看 SFTP 目录并下载文件。这里会连接真实服务器。

## 域名、邮箱与证书

域名填可查询的域名名称并刷新；到期信息受 WHOIS 服务可用性影响。证书填实际 TLS 主机，查询签发者、有效期和信任状态。邮箱使用服务商的 IMAP 授权码或配置方式，网页身份授权与邮箱 IMAP 密码不是同一项能力。

## 组织资产

资产支持多个标签。搜索与标签可以组合使用；卡片适合浏览、表格适合排序比较、关系图适合看连接。详情中建立关联后，两端都能跳转。需要留意的事项可导出 ICS，导入常用日历。

## 连接模型

进入「设置 → 模型与知识库」。选择服务商预设或编辑 API Base URL，填写 API Key 与模型名。点击「读取模型」获取服务端支持列表，点击「测试连接」确认真实推理返回。

Base URL 必须属于提供 Key 的服务。切换地址后旧 Key 关联会被清除，需要重新填写。模型必须支持 OpenAI Chat Completions 和工具调用；只支持其他协议的接口需要服务商提供兼容网关。

## 导入知识与问答

在模型设置中导入 TXT 或 Markdown，单文件不超过 500 KB。返回问答页面发送问题，可查看检索和工具阶段，也可停止生成。回答中的标题、列表、表格、代码块按 Markdown 展示，展开「检索来源」查看依据并跳转资产。

不要把主密码、私钥或服务 Token 放入文档和提问。自动索引会排除资产凭据字段，但用户主动输入的文字不会自动变成保密字段。

## 查看 AI 订阅额度

在模型设置下方找到「AI 服务账号」，解锁密钥库，选择 OpenAI、Claude、Grok 或 Gemini，并在打开的系统浏览器中登录。Claude 完成后需将 `code#state` 粘贴回应用，其他三家等待本机回调。点击账号右侧刷新图标查询额度。具体条件见 [服务商授权教程](AI-ACCOUNTS.md)。

## 备份与恢复

资产 JSON 导出用于资产记录迁移，不含密码、OAuth 令牌和聊天记录。完整备份前先从托盘退出程序，再复制设置中显示的数据目录。恢复前保留当前目录副本，操作系统加密的模型 Key 跨机器迁移后可能需要重新录入。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 主密码错误 | 使用原密码；软件不提供找回或后门重置 |
| 模型返回 401 | 检查 Key、Base URL 和服务商账号权限 |
| 模型不支持工具 | 改用支持工具调用的模型或兼容网关 |
| 授权回调端口被占用 | 结束其他同服务商登录流程后重试 |
| 授权页面拒绝客户端或地区 | 核对服务商限制，使用 API Key 接入模型 |
| Gemini 无项目 | 先在 Gemini CLI 完成 Code Assist 开通，再重新登录 |
| 未显示订阅到期 | 接口未提供该字段；以服务商账单页面为准 |
| Markdown 中的图片不显示 | 文档远程图片默认不加载，避免向图片服务器泄露访问情况 |
