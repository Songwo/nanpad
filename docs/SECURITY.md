# 安全与备份

## 存储边界

| 文件                                                   | 内容与保护                                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `profile.json`                                         | 本机姓名与头像，明文                                                                    |
| `assets.json`                                          | 资产元信息、关联、邮箱分组、账号头像及自定义发件人头像和地址对应关系，明文              |
| `conversations.json`                                   | 问答及来源，明文                                                                        |
| `documents/`                                          | 工作区文档、网页正文快照与来源链接，明文                                                 |
| `knowledge.json`、`rag-index.json`、`rag-vectors.json` | 导入文档和检索缓存，明文                                                                |
| `metrics.json`                                         | 指标历史，明文                                                                          |
| `vault.enc`                                            | 主密码派生密钥保护的 AES-256-GCM 网站/邮箱/SSH 凭据、OAuth 令牌、邮件推送配置和邮件草稿 |
| `agent-config.json`                                    | 模型配置，其中 API Key 使用 Electron safeStorage 加密                                   |
| `mailbox-baselines.json`                               | 邮箱 UID 检查基线，明文；不保存邮件内容或认证凭据                                       |

数据目录在「设置 → 数据」查看。Windows 通常位于当前用户 AppData 下的 Nanpad 目录，以界面实际显示为准。

## 主密码

首次创建至少 10 位。应用不保存主密码，不提供密码找回。升级时原有密码继续可用，修改密码需要输入原密码。密钥库损坏时拒绝创建覆盖，先保留原文件并检查备份。

锁库保护凭据，不是整个应用的登录锁。资产与对话仍可见，操作系统安全存储加密的模型 Key 也不由主密码派生。因此不要把未加密的本机资料视为密码保险箱。

## 网络边界

SSH、邮箱探测、WHOIS、TLS 和模型请求会连接填写的远程服务。用户问题、历史上下文和命中文档会发送到配置的模型。OAuth 只连接适配器指定的供应商端点，不接受渲染进程传入任意 Token URL，也不记录服务返回的令牌正文。

网站账号的登录地址、用户名、密码和加密账号备注不会进入自动资产索引或资产 JSON 导出。资产普通名称、提示、标签和说明仍是明文；用户把密码手工放进提问、近期对话或导入文档后，不能依靠凭据库的隔离保护这些副本。

凭据定位只返回本机资产位置，不读取加密库、不确认密码是否存在。实时邮箱工具需要用户为当前问答启用「本次允许查询邮箱」；本机服务用已保存凭据完成 IMAP TLS 认证，只把数量和时间交给模型。Agent 使用的数量查询不下载标题、正文和附件，不自动标记已读。邮箱登录密码仍会作为认证材料发送给用户配置的邮箱服务，不能把“不发给模型”理解为“不离开本机”。

本地邮箱目录工具可查询分组名称、账号数量、邮箱地址、类型及归属，不连接邮箱服务器，也不需要实时查询许可。这些元信息会发送给配置的模型，密码、邮件正文、草稿、账号图片和自定义发件人头像映射不进入工具结果或自动资产索引。用户主动输入到问题、对话或导入文档中的副本不受这条字段白名单保护。

邮件工作台由用户直接操作，通过 IMAP 读取邮件和附件，通过 SMTP 发送确认后的内容。HTML 在主进程使用白名单净化，再由阅读器只展示允许的静态元素和有限文字样式；脚本、表单、嵌入网页及外部样式被移除。纯文本邮件可按 Markdown / GFM 排版，也可查看解析后的原文。正文不进入 Agent/RAG 索引；退出阅读区或锁库后清除界面内存。

正文外部图片默认不会发出请求，只有点击「加载本封图片」后才加载；授权按邮件记忆，最多保留 500 封，可在「设置 → 存储」清除。图片请求不携带页面 Referer，但图片服务器仍可能得知 IP 地址、访问时间和 URL 中的跟踪标识。点击隐藏不能撤回已经发出的请求。符合格式、尺寸和数量限制的 CID 内嵌图片来自已经读取的邮件，在本机展示；应用不自动向外部服务查询发件人头像。本地自定义头像及对应地址是明文资产数据，导出资产时也会带出。

每个邮箱的本机草稿包含正文、收件人与附件，保存在 `vault.enc`。手动下载附件会生成用户选择的普通文件，不再受主密码库保护。SMTP 只接受 TLS 或强制 STARTTLS 并验证证书；锁库取消进行中的连接，但已被服务商接受的邮件无法撤回，结果不明时不会自动重发。

邮件推送默认关闭，用户保存配置后才启用。Bot Token、SendKey、机器人 Key 和目标配置保存在主密码库，接口返回给界面的配置不含令牌。通知发送到选定渠道的固定 HTTPS 端点，只含新增数量、相关邮箱未读数量及检查时间，不含邮箱地址或邮件内容。渠道本身会接收到通知和必要的认证信息。锁库或退出后停止新的检查及推送；已被远端接收的请求无法撤回。第三方网络超时重试可能出现重复通知。

文档和模型回答的 Markdown 不执行原始 HTML，不自动请求远程图片；邮件正文使用上述单独的图片许可。两者均不允许 `javascript:` 等外链协议，外部 HTTP/HTTPS 链接交给系统浏览器打开。

缓存边界（0.9.0）：问答检索索引缓存只含资产白名单元信息与导入文档片段，与模型上下文同界；邮件正文、附件与列表的会话缓存只存在内存，锁库或标记已读即清除，不落盘；远程图片授权记忆只保存邮件 Message-ID 列表（界面偏好，不含图片地址或内容），存于浏览器本机存储，可在「设置 → 存储」清除。缓存不会主动读取主密码库的密码、令牌或密钥值；用户自行写入文档或问题的敏感文本不能被保证自动脱敏。

## 浏览器密码迁移

Chrome / Edge 密码迁移使用浏览器官方导出、导入的 CSV，不读取原生密码数据库或绕过操作系统身份验证。CSV 只在桌面主进程解析；渲染界面接收不含密码的预览和短期票据。确认后批量写入 AES-256-GCM 主密码库；关闭、取消、过期或锁库会撤销尚未提交的预览。相同站点不同用户名分别保存，完全重复跳过，导入密码冲突保留现有记录、不自动覆盖。

预览中的网站、用户名与标题仍是个人信息，截图时应检查。导入完成后的普通资产数据不含账号网址、用户名和密码，但保留显示名称等元信息。加密记录同时保存可恢复的资产描述，避免写入凭据后意外退出导致找不到账号。

导出需要解锁、界面明确勾选和系统再次确认，只导出可用于浏览器密码管理器的账号记录。CSV 包含**明文网址、用户名、密码及敏感备注**，不受主密码库保护；应保存在自己控制的目录，浏览器导入后删除，不共享或用表格软件打开。文件保留真实密码字符，不能用给公式前缀添加字符的方式改变密码。资产 JSON 导出仍不包含这些凭据。

## 浏览器插件

1.3.0 插件自动识别顶层网页的可见登录表单，用户也可打开弹窗核对。默认开启的「登录时自动采集」在提交时读取该表单或就近容器的账号密码，先显示保存提示；用户确认后才直接写入知屿加密库，无需桌面二次确认。关闭该开关会停止提交采集，账号建议与文档提示有独立开关。插件不访问浏览器原生密码库、Cookie 或浏览历史，采集结果来自网页，仍可能识别错误。

桌面连接只监听 `127.0.0.1:47832`，不监听局域网地址。生成配对码需要解锁密钥库；随机配对码包含 64 个十六进制字符，5 分钟有效、使用一次后失效。后续请求使用绑定扩展来源的随机令牌认证，服务检查来源、Host、请求格式、大小及频率。普通网页不能直接调用此保存接口。

账号密码走认证的本机 HTTP POST，不放进 `nanpad://` 链接、URL 查询参数或日志，也不经云端转发。本机 HTTP 不是 TLS 加密通道；这些校验不能防御已经控制本机或浏览器进程的恶意程序。只记录站点的旧入口使用 `nanpad://`，仅传网站名称及去掉路径、嵌入凭据、查询参数和片段的站点根地址。

账号建议按精确 origin（协议、域名和端口）匹配，不扩大到子域名。用户选择后才读取密码并填写，不自动提交登录。桌面使用绑定客户端、站点与候选账号的一次性短期选择票据；扩展后台同时核对标签页、顶层 frame 和导航状态，防止跨站读取或填入已经跳转的页面。远程 HTTP、隐藏字段、注册/改密表单、iframe、封闭 Shadow DOM 与第三方 OAuth 不作为自动填写目标。

提交后待确认的凭据仅在扩展后台内存保留，最多 2 分钟；休眠、关闭标签页或失去连接可能提前失效。确认后密码写入主密码库，不进入普通资产快照、自动 RAG 索引或模型上下文。站点名称、标签和普通说明仍是明文元信息，应检查网页标题是否带有个人信息。旧版插件的桌面待确认队列继续兼容，最多 10 条、每条 5 分钟；锁库、撤销连接或退出会撤销桌面授权并清除其待确认队列。

扩展把连接令牌保存在 `chrome.storage.session`，开关偏好保存在本机存储；不使用浏览器同步存储或持久化保存密码。浏览器会话结束后需要重新配对。连接令牌不交给网页，配对码、选择票据和令牌不要放进截图、问题报告或网页输入框；主密码始终在知屿桌面端输入。填写后网站自身可以读取其输入框，请核对访问的网站。本机控制权被窃取、浏览器被恶意扩展控制或账号目标站点被入侵，不在这些检查能够完全防御的范围内。

文档提示自动出现，但点击保存后才提取已加载的可见正文。内容以纯文本和来源链接写入普通本机文档，不执行网页脚本，不保存表单、隐藏内容或未加载页，不绕过访问权限；同来源去重并保留已有本机编辑。网页文档不属于凭据保险箱，其正文与其他工作区文档一样，只有在本次问答获得正文许可时才可发送给模型。

## 备份

1. 从托盘退出知屿，确保文件写入已经结束；数据目录名称仍使用 Nanpad。
2. 将完整数据目录复制到受保护的位置，备份文件包含个人元信息和加密凭据。
3. 单独妥善保管主密码。
4. 恢复前先备份当前目录。跨机器恢复后，操作系统加密的 API Key 可能无法解密，应重新录入；主密码库使用原密码解锁。

资产 JSON 导出不是完整备份，不包括主密码库、聊天记录和 AI 授权。分享问题报告前移除主机地址、账号、Key、Token、文档和对话内容。

公开源码前还应检查 Git 历史、文档附件和截图；在新提交中遮挡图片不能移除历史版本中的信息。分享 OAuth 问题时不要附上完整回调链接，因为其中包含一次性授权码和会话状态。

## 1.2.0 文档授权与本机用量

工作区文档默认只有标题、时间与关联元信息可进入问答上下文。正文需要每次发送前明确授权；授权片段发送至配置的模型服务，并可能保存在本机问答历史。未再次授权时，带正文使用标记的旧回答不会回传模型。该开关不撤回服务商已经收到的内容，也不替代文档与聊天文件的本机访问控制。

本机 Token 监控只解析支持客户端日志中的用量数字与必要去重标识。持久缓存不保存提示词、回答正文、凭据或原始日志路径；只读扫描限定可信根，拒绝根下的链接逃逸、硬链接文件和文件替换。锁定主密码库时暂停新采集。

Windows 系统透明重定向仅对应用自己的统计缓存开放兼容：逻辑路径与实际路径均不得含符号链接，必须指向相同文件身份。该兼容不放宽客户端日志目录的路径校验，不申请管理员权限，不清空已有统计。
