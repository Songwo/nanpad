# 司南产品介绍

司南面向维护多种数字资产的个人开发者、独立产品负责人和小型运维场景。主机、域名、证书和 AI 订阅不再分散在多个记录表中，可以按项目标签聚合，再通过关系图查看依赖。

## 日常场景

早上打开总览，检查离线资产和即将到期的项目。进入主机详情比较近期 CPU、内存与磁盘变化，需要操作时打开 SSH 终端。查看域名及证书关联，避免只续费域名却漏掉证书。为同一产品的主机、域名、邮箱和密钥打相同标签，在分组视图集中维护。

AI 订阅可以通过快速登录关联账号，按来源查看可读取的分类额度和重置时间。不同服务商公开给客户端的范围不同：Codex、Claude OAuth、Grok CLI、Gemini Code Assist 的额度不能统一视作网页订阅的完整权益。接口拒绝访问时显示错误，刷新失败时标明上次查询结果，方便判断数据是否仍可参考。

## AI 的职责

把运维手册导入本地知识库后，可以询问「哪些资产需要优先处理」「这个域名关联哪些主机」「本月 AI 订阅费用是多少」。模型根据当前记录与检索片段回答，引用来源可展开核对。

模型不是监控事实的来源，也不会自动替你执行修复。主机状态由实际探测产生，金额和日期以资产记录或服务商返回值为准。遇到风险操作，仍由用户通过原有界面执行。

## 本机工作方式

桌面端保留资料、资产、指标和对话，凭据单独加密。无账号云同步、团队权限和后台托管服务。首次设置的姓名用于本机身份展示，主密码用于打开加密凭据库。个人头像和资产图片可从本地文件上传、更换或移除，图片处理与保存也在本机完成。

## 0.2.2 的变化

等待 AI 登录授权时直接显示回调输入框，并分别展示等待回调、验证授权和同步额度。账号授权已保存在本机时单独显示状态，额度查询失败不会被误解为仍需填写回调。HTTP 403 仅表示请求被拒绝，具体原因仍需核对服务商，本版不声称解决了真实账号的额度访问限制。已有分类额度、主题化下拉菜单、头像和资产图片功能继续保留。详细操作和限制见 [使用教程](USER-GUIDE.md)。
