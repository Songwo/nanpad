# 司南 Nanpad 0.5.0

本版增加文件夹收纳和桌面邮件工作台，让多个邮箱可以按用途整理，并在司南内处理日常邮件。

- 默认工作邮箱、生活邮箱和未分组，支持自定义名称与颜色、重命名、删除分组和批量移动。删除分组不删除账号。
- IMAP 文件夹、分页、主题与发件人搜索、仅未读、纯文本正文、显式已读与附件下载。
- SMTP 写信、抄送、密送、回复、文本转发和附件；发送前显示确认，未知结果不自动重试。
- 每个邮箱一份加密草稿，支持保存与恢复。锁库清除阅读状态并取消连接，正文不进入 Agent/RAG。
- 邮件窗口适配窄屏；使用教程、产品介绍、安全说明和版本记录同步更新。

详细配置见 [邮箱工作台教程](../MAIL-WORKSPACE.md)。安装包为 `Nanpad-0.5.0-setup.exe`，扩展包为 `Nanpad-0.5.0-browser-extension.zip`。

## 使用边界

本版通过密码或客户端授权码连接 IMAP/SMTP，不支持只允许邮件 OAuth 的账号。邮件正文以纯文本显示，不是完整 HTML 邮件客户端；不提供邮件删除、联系人同步或后台完整缓存。转发不自动携带原附件，服务商是否保存到已发送文件夹以其 SMTP 行为为准。AI 服务网页登录授权与邮箱邮件授权是不同权限。

真实私人邮箱登录和最终邮件投递尚未验收；自动化使用隔离数据和网络 fixture，不向真实收件人发送邮件。Windows 安装包未签名，尚未执行 NSIS 安装、升级、卸载的完整系统测试。服务商网页套餐权益仍以各接口实际返回为准。
