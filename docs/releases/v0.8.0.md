# 司南 Nanpad 0.8.0

本版为浏览器插件增加可选的登录自动采集，改进模型与知识库配置体验，并修复日常数据迁移后问答不可用的问题。

- 插件新增「登录时自动采集」开关（默认关闭）。开启后提交含密码的登录表单时，自动读取该表单的账号密码并发送到司南待确认队列，页面右下角提示结果；桌面端核对后才写入主密码库，且不会把司南窗口抢到前台。
- 自动采集经扩展后台服务（service worker）转发，连接令牌仍只保存在浏览器会话中，不进入网页；开关关闭后内容脚本立即停止监听。无 `<form>` 结构的纯脚本登录、iframe、封闭 Shadow DOM、通行密钥及 OAuth 登录不在采集范围。
- 「设置 → 模型与知识库」：服务商下拉显示当前生效的地址，非预设地址标记为自定义；点击「读取模型」后出现可视模型选择列表并显示已加载数量，仍可手动输入模型名。
- 问答范围限定在资产、凭据、邮箱、AI 订阅、知识库与软件使用等主题；范围外的问题会说明边界并婉拒。
- 修复：日常数据从其他环境（如沙盒目录）迁移到标准数据目录后，操作系统加密的模型 API Key 无法解密导致所有问答报错。现在配置页会显示明确的重新输入提示，运行错误也会指向「设置 → 模型与知识库」。
- 修复一处中英文文案不一致（桌面版 / 桌面端）导致的国际化检查失败，这是 0.7.0 发布时遗留的问题。

安装包命名为 `Nanpad-0.8.0-setup.exe`，扩展包命名为 `Nanpad-0.8.0-browser-extension.zip`；可用下载以 [GitHub Releases](https://github.com/Songwo/nanpad/releases) 为准。插件教程见 [BROWSER-EXTENSION.md](https://github.com/Songwo/nanpad/blob/main/docs/BROWSER-EXTENSION.md)。

## 使用边界

自动采集默认关闭，开启需要显式操作；未配对或密钥库锁定时只提示、不发送。自动采集的账号与手动发送走同一待确认队列（内存中最多 10 条、每条 5 分钟、锁库清除），桌面端「核对账号并保存」前不写入密钥库。频繁提交受每客户端每分钟 30 条限制。

桥接协议新增唯一可选字段 `source: "auto"`：仅接受该值，用于桌面区分自动与手动采集并决定是否聚焦窗口；其余键校验保持 0.7.0 的严格程度。普通网页发出的请求仍被来源校验拒绝，令牌依旧绑定扩展来源。

Windows 安装包未签名，下载后应核对 Release 的 SHA256 文件。NSIS 完整安装、升级和卸载流程仍未经实际验证。
