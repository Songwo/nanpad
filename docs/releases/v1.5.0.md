# 知屿 Zhiyu 1.5.0

让文档、账号与资产在同一工作区中更容易阅读、关联和修改：全局导入 Markdown、目录定位、就地解锁、真实关系图、可审阅的 AI 修改建议，并复用已有统计和检索结果，减少切页时的重复加载。

## 文档与界面

- 文档「＋」菜单包含新建与 Markdown 导入；在任意页面拖入 `.md` / `.markdown` 后打开导入的文档，保留批量结果与失败原因。
- 阅读区增加目录、当前章节、阅读进度、顶部／底部跳转；收起列表后仍可使用，重复标题可分别定位。
- 设置与锁库入口固定在侧栏底部，调整折叠导航的图标、选中背景与间距；过渡动画支持减少动态效果设置。
- 用量页通过「采集与监控」展开客户端状态和开关，图表与明细保留在主页面。

## 账号与真实关系

- 点击账号整行即可查看详情，锁定时在原处解锁并继续操作；本次运行无需因保存或切页重复解锁，主动锁定、锁屏、休眠或退出后重新锁定。
- 全局关系图同时展示已保存的资产关联与文档绑定，分类页也可带出相连的其他类型资料。
- 「管理资源关联」支持新增、解除与确认建议；本机「发现关联」按地址、标签和标题给出依据，不读取密码或文档正文。
- 建议确认后才成为已保存关系。当前不支持两篇文档直接连线，可通过共同账号或服务器组合；画布最多显示 300 项资源，超过时提示缩小筛选。

## AI 重试与修改建议

- 错误回答提供「重试这条问题」和模型设置入口，使用当前配置与当前勾选权限，不自动恢复旧的正文或邮箱许可。
- 开启「本次生成修改建议」后，可提出文档局部替换、账号名称／标签、资产关联或文档绑定建议；逐项展示依据与修改前后内容，点击确认后才保存。
- 文档替换需要本次正文授权，并在同一个文本节点中唯一匹配原文；不支持跨段落或跨格式节点的整篇改写。账号用户名、网址、密码及敏感备注仍在本机账号面板编辑。
- 确认前校验资料版本；目标已变更、删除或建议已处理时拒绝写入。建议 30 分钟有效，软件重启后需重新生成；建议预览随问答保存在本机历史。
- 鉴权错误仍需有效的模型地址、API Key 与模型配置；重试入口不会绕过服务商权限。

## 缓存与加载

- 切换用量页先显示已有快照，10 秒内复用读取；同一时刻的重复请求合并，不因展示统计而触发远程采集。
- 自动远程用量采集复用最近 5 分钟成功或失败的状态，自动主机检查复用最近 90 秒结果；手动刷新仍请求最新数据，失败保留上次结果并提示错误。
- 文档保存、删除与批量导入按篇更新缓存，保留编辑中的草稿；一次导入 50 篇也不反复读取整个列表，只有旧式无变更详情的通知才回退到全列表读取。资产与知识文件未变时复用检索索引。
- 本机 Token 监控继续默认开启，无需解锁，增量读取支持客户端日志；缓存优化不扩展到没有用量日志的客户端或网页聊天。

## 升级与边界

1.4.0 用户可在「设置 → 关于」检查并下载更新，校验完成后重启安装；更早且不支持应用内安装的版本需先运行新版安装包。继续使用原数据目录，升级前请备份完整资料。配套浏览器插件版本为 1.5.0，桌面安装器不会自动替换浏览器中的旧插件，需在扩展管理页重新加载。

本版提供未签名的 Windows x64 安装包。资产元信息、文档、统计与问答历史没有整体加密，账号凭据保存在主密码库；文档正文授权和建议确认不改变这一存储边界。详细说明见 [安全与备份](../SECURITY.md)。
