# 司南 Nanpad 1.1.1

1.1.1 继续改善个人资产记录的日常使用体验，重点是常用入口、号码与订阅关联，以及大量记录时的搜索和浏览。

- 总览优先显示文档、号码、订阅和用量操作；终端和 AI 助手归入「更多工具」，展开状态保存在本机。手机底栏增加文档和号码入口。
- 号码每页显示 50 条，搜索与筛选面向全部记录；条件变化后回到第一页，提供清除搜索和重置筛选。
- 全局搜索完整匹配后最多展示 60 条，支持不带分隔符的号码、多关键词和全角字符，同名记录可分别选择。
- 号码卡片可打开关联订阅，订阅详情可定位回具体号码。关联订阅支持名称、邮箱和服务商搜索，保留已有选择；大量可关联号码也支持搜索并限制下拉选项数量。
- 到期通知定位对应号码，总览的号码待处理入口直接进入需关注筛选。清理重复标题及「挂载」「沙箱」等不直观文案。
- 同一号码保存为多条记录时，搜索、订阅详情和通知按记录 ID 精确定位，提供「查看全部号码」返回入口。修复手机固定底栏遮挡号码分页按钮的问题。

沿用已有数据格式，未改动凭据加密和图床配置。高 DPI 验收包括模拟环境，尚未完成所有真实显示器及真人试用验证。号码是手动台账，不提供短信接收或自动续费。
