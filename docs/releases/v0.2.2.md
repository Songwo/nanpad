# 司南 Nanpad 0.2.2

本版调整 AI 登录的回调入口与阶段提示，帮助区分等待授权和额度同步失败。

## 登录与用量

- 发起网页登录后直接显示「回调链接或授权码」输入框，无需另行展开。没有自动返回时，可提交本次登录生成的完整回调链接；Claude 也可提交网页给出的 `code#state`。
- 等待回调、正在验证授权和正在同步额度分别显示。自动回调已处理后无需再次粘贴；本机已有授权的账号单独显示「本机已保存授权」。
- 额度同步失败时明确显示失败状态；HTTP 403 提示请求被拒绝，不推断具体上游原因，也不把它解释为缺少登录回调。
- 调整通用 HTTP 403 / 429 提示，避免令牌请求失败时误写成额度查询失败。

回调与本次 PKCE 会话绑定。取消、过期或完成后，旧回调不能用于新的登录；重新授权需要从应用发起并使用新的回调结果。完整回调链接含一次性授权信息，不要上传到公开反馈或日志。

## 安装与升级

Windows x64 安装包名为 `Nanpad-0.2.2-setup.exe`。安装包校验值由发布时的 `SHA256SUMS.txt` 提供。当前构建未配置代码签名；升级前备份数据目录，保留原有资产、资料和主密码，无需删除数据重新设置。

## 授权范围与已知限制

OpenAI 读取的是 Codex 额度，Claude 读取 OAuth 返回的共享与模型额度，Grok 读取 CLI 账单与额度，Gemini 读取 Code Assist 模型额度。这些接口不等于各家网页订阅的全部权益。OAuth 用于账号和额度查询，模型问答仍需单独配置 OpenAI 兼容 API Key。

本版未确认真实账号 HTTP 403 的具体上游原因，不声称已经修复该拒绝。已保存的授权与额度读取权限是两个结果；自动化协议测试也不能证明每个私人账号、地区或网络均可读取额度。
