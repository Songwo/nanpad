# 知屿 Zhiyu 1.4.0

新增 Markdown 快速导入、本机默认用量监控和应用内下载更新。文档导入后可直接阅读、编辑和关联资产；本机监控无需解锁密钥库，更新下载完成后可在软件内重启安装。

## 文档导入

- 在文档列表上方点击「导入 Markdown」或拖入文件，支持 `.md` / `.markdown`，每次最多 50 篇、每篇最多 1 MiB。
- 支持 UTF-8 与带 BOM 的 UTF-16，转换常见标题、列表、引用、代码、文本格式和 HTTP(S) 链接。
- 同名创建独立文档，单篇失败不阻止后续导入；保存后重启可继续阅读、编辑。
- 图片保留为链接或源文本，不自动加载；表格、HTML 和脚注等暂不支持的结构保留原文并提示。

## 本机监控

- 新配置默认开启，不需要解锁；锁库后照常采集支持客户端的本机 Token 日志。
- 主动关闭会保存选择；已有关闭设置可在用量页面直接开启，无需主密码。
- 只汇总日志提供的数字，不保存对话内容或密钥。远程 API、邮箱、账号等凭据功能仍需解锁。

## 应用内更新

- 设置 → 关于支持检查、下载进度、校验完成后重启安装，失败可重试。
- 更新源固定为本仓库 GitHub 正式版，下载后和安装前校验 SHA512，保留原安装位置和数据目录。
- 不在普通退出时自动安装；点击安装前会保存文档，保存失败阻止安装。
- 1.2.3 等旧版需要先安装一次 1.4.0，之后可使用应用内更新。
- 本版继续提供未签名的 Windows x64 安装包；校验摘要不等于发布者数字签名。

配套浏览器插件版本同步为 1.4.0。已有插件不会由桌面安装器自动替换，可从本发布下载后在浏览器扩展管理页重新加载。

## 验证

- 类型检查、国际化检查、网页和 Windows 桌面构建通过；706 项自动测试通过。Lint 无错误，保留 19 条已有警告。
- 实际打包程序验证 Markdown 多选、拖入、同名独立保存和退出后恢复；浏览器密码迁移、插件交互和彩色图标回归通过。
- 锁库状态下使用合成日志验证后台定时采集；更新引擎验证真实 HTTP 下载及错误 SHA512 拒绝，更新界面验证文档保存失败时阻止安装。
- 所有自动测试使用隔离数据，不将真实个人资料作为测试样本。
