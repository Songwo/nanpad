# 知屿 Zhiyu 1.2.3

修复软件内和桌面 Logo 已更新，但 Windows 任务栏仍显示旧司南图标的问题。

## 修复内容

- Windows 任务栏分组切换到知屿专用的 `dev.songwo.zhiyu` 身份，运行窗口、桌面入口与开始菜单入口一致，避免继续沿用旧 Nanpad 分组。
- Windows 系统显示名和通知来源统一为「知屿 Zhiyu」，防止运行时再次按旧名称生成入口。
- 显示身份与存储身份分开：固定原 `Nanpad` 数据和 Chromium 会话目录，保留显式 `--user-data-dir` 设置；开发测试同时隔离数据与会话。
- 安装程序继续使用原安装身份和文件名，支持覆盖升级；无需搬迁资料、重新设置主密码或重新配对插件。
- 发布检查新增真实窗口的任务栏属性验证，包括 AppUserModelID、重启图标、程序路径和显示名，补充数据目录兼容测试。
- macOS/Linux 保留原系统密钥存储身份，避免 Windows 改名影响已有加密凭据。

## 验证

- 650 项自动化测试通过，类型检查、多语言检查、网页构建及 Windows 安装包构建通过。
- Lint 为 0 错误，保留原有 19 条警告。
- 真实打包程序通过浅深主题彩色 Logo、EXE 图标、任务栏窗口属性与数据/会话目录隔离检查；首次设置、保存与重新载入、四档缩放通过。
- 开发与生产网页均通过桌面和移动端渲染检查，无横向溢出和浏览器异常。
- Windows 本机从 1.2.2 覆盖升级到 1.2.3，通过桌面入口启动后，实际任务栏分组为「知屿 Zhiyu」，任务栏截图确认显示新版彩色图标；桌面及开始菜单身份检查通过。

## 升级

安装 `Nanpad-1.2.3-setup.exe`，从「知屿 Zhiyu」入口启动。已手动固定在任务栏的旧入口属于 Windows 的固定项，若升级后仍单独保留旧固定项，可取消固定旧项，再固定正在运行的知屿窗口。

本版不清空全局图标缓存，不重启资源管理器。Windows 安装包当前未做代码签名；安装包、浏览器插件及 `SHA256SUMS.txt` 随 Release 提供。

完整历史见 [更新日志](https://github.com/Songwo/nanpad/blob/main/CHANGELOG.md)，1.2 系列功能见 [1.2.1 发布说明](https://github.com/Songwo/nanpad/blob/main/docs/releases/v1.2.1.md)。
