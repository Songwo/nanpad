# 司南 Nanpad 1.1.0

1.1.0 改善从第一次打开到日常记录的操作流程：看清界面、快速录入、写带图文档、连接流量与 API 用量，并新增与 AI 订阅关联的号码台账。

## 本版变化

- 使用本机系统字体，改善辅助文字对比度；100%、110%、125%、150% 界面大小可保存，支持快捷键和恢复默认。窗口初始尺寸适应屏幕工作区，弹窗稳定后解除多余模糊和合成状态。
- 首次设置给出默认工作区名称，无需注册，头像稍后再配。主密码校验和凭据加密继续保留。
- 服务器可仅记录名称和地址，SSH 配置按需展开，高级字段在编辑中继续保留。尚无实际观测时显示“未采集”。
- AI 添加流程区分订阅账号、API 调用用量与手动记录。订阅额度快照不冒充精确 API Token 统计。
- 服务器资料统一进入图文文档并自动保存。旧 Markdown 提供显式迁移，完整原文保存在代码块中；旧记录不清理，重复迁移不覆盖后续编辑或解绑。
- 图片插入成为主要操作，显示保存位置、处理进度和失败重试。部分图片上传失败时保留成功项；图床配置和已有内嵌图迁移放在次级选项。
- 节点保存或导入后继续连接流量来源，带入所属节点信息；3x-ui / 机场表单按来源显示，高级筛选按需展开。点击“保存并验证连接”后验证一次，失败保留来源与上次数据。
- 新增号码台账，记录号码、服务商、到期日期并绑定 AI 订阅，订阅详情可查看关联记录并返回管理。

## 下载与升级

从本仓库 Releases 下载 `Nanpad-1.1.0-setup.exe`（Windows x64），对照 `SHA256SUMS.txt` 核验文件。安装包目前没有代码签名。升级前备份原数据，继续使用原主密码，不要删除 Nanpad 数据目录。

已有服务器文档不会自动转换或清理，需要时再点击迁移。图床默认设置沿用原配置；改变新图片保存方式不会自动上传历史图片。普通资产导出不包含加密凭据库，完整备份见安全文档。

## 验证范围与使用边界

文档回归覆盖原文、代码和链接保留，重复／并发迁移不覆盖编辑，保存失败保留原文，以及编辑、解绑和刷新后的持久化。图片 UI 回归使用隔离图床样本验证部分失败后重试，不代表所有真实图床和账号都已验收。整体发布构建由仓库的 Windows 工作流校验。

- 高 DPI 可读性仍受屏幕、系统缩放、驱动与远程桌面环境影响，不承诺消除所有硬件环境的模糊。
- 组织 API 用量需要相应权限；订阅额度不等同于精确 Token 或账单费用，未返回的数据不会估算成真实值。
- 号码是用户维护的台账，不提供号码购买、短信接收、接码或自动续费；号码和普通备注不是加密凭据。
- 图床上传会发送所选图片；服务器、邮箱和服务商连接会请求对应的真实服务。
- macOS / Linux 尚未提供经过验证的本版安装包。
- 已准备 3～5 位目标用户的任务测试表，尚未完成真人试用。自动化回归不替代真人测试结果。
