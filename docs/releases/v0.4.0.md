# 司南 Nanpad 0.4.0

本版把网站快速保存、批量整理与更便捷的关联操作接入现有桌面工作流。

- Chrome / Edge 扩展可从当前网页唤起司南，预填站点并等待用户确认；账号与密码在桌面端填写和加密保存。
- 网站账号表单可直接关联注册邮箱；请求队列不覆盖正在编辑的表单。
- 批量整理支持按名称或类型搜索、多选、增删标签，以及统一关联目标资产。
- 资产详情支持搜索多选关联，关系图支持手动连接端点；去重、自关联和悬空引用规则继续生效。
- 版本号、插件版本、README、使用教程和更新日志同步至 0.4.0。

安装包为 `Nanpad-0.4.0-setup.exe`，扩展包为 `Nanpad-0.4.0-browser-extension.zip`。扩展尚未上架商店，按 [浏览器插件说明](../BROWSER-EXTENSION.md) 加载。Windows 安装包未签名。

插件没有密码抓取、自动填充、Cookie 读取或云端中转。网页订阅权益依旧以服务商实际返回为准；本地 RAG 命中的非凭据内容会发送到用户配置的真实模型。没有将真人账号未验证的网络链路描述成已验收。
