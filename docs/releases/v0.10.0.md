# 司南 Nanpad 0.10.0

本版让自动采集开箱即用，并为密钥带来分组收纳。

- 「登录时自动采集」**默认开启**：配对并解锁后，在网站提交登录即自动进入司南待确认队列，不再需要先到弹窗打开开关；仍可在插件弹窗中一键关闭，关闭后不监听任何表单。
- 自动采集覆盖**无表单的脚本登录**：没有 `<form>` 结构的站点，点击「登录」类按钮时按就近容器采集账号密码；同一页面重复提交（连点、失败重试）只发送一次。
- 边界不变：OAuth / 快捷登录（扫码、一键登录）没有密码输入，无法采集；通行密钥、验证码同样不在范围。到达司南后仍需「核对账号并保存」才写入密钥库。
- 新增**密钥分组**：密钥页按分组收纳（默认「工作密钥 / 个人密钥」），分组卡片显示数量与前三个条目；组内支持全选、批量移动、从组内新建密钥；分组可重命名、换色、删除（只解除归属，不删除密钥）。
- 问答新增**密钥分组查询**：可以问「工作密钥里有哪些」「未分组的密钥有多少」；工具只返回名称、类型与分组归属，密钥值与提示永不进入索引或模型上下文。
- 卡片视图的密钥页改为分组工作台；表格与关系图布局保持原有行为，密钥仍参与关系图与导出。

插件需升级到 0.10.0 配套版本（桌面「设置 → 浏览器插件」可一键下载）。安装包命名为 `Nanpad-0.10.0-setup.exe`，扩展包命名为 `Nanpad-0.10.0-browser-extension.zip`；可用下载以 [GitHub Releases](https://github.com/Songwo/nanpad/releases) 为准。

## 安全边界

自动采集默认开启是产品决策：内容脚本在所有 HTTP / HTTPS 页面监听密码表单提交与登录按钮点击，但只在触发瞬间读取该表单或就近容器的账号与密码；未配对或已锁库时不发送任何内容；令牌只在扩展会话中流转。密钥分组为明文元信息（与资产标签同级），分组内密钥的值与提示仍只存在 `vault.enc`，RAG 索引与模型工具均不包含。
