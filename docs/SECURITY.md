# 安全与备份

## 存储边界

| 文件 | 内容与保护 |
| --- | --- |
| `profile.json` | 本机姓名，明文 |
| `assets.json` | 资产元信息和关联，明文 |
| `conversations.json` | 问答及来源，明文 |
| `knowledge.json`、`rag-index.json`、`rag-vectors.json` | 导入文档和检索缓存，明文 |
| `metrics.json` | 指标历史，明文 |
| `vault.enc` | 主密码派生密钥保护的 AES-256-GCM 凭据和 OAuth 令牌 |
| `agent-config.json` | 模型配置，其中 API Key 使用 Electron safeStorage 加密 |

数据目录在「设置 → 数据」查看。Windows 通常位于当前用户 AppData 下的 Nanpad 目录，以界面实际显示为准。

## 主密码

首次创建至少 10 位。应用不保存主密码，不提供密码找回。升级时原有密码继续可用，修改密码需要输入原密码。密钥库损坏时拒绝创建覆盖，先保留原文件并检查备份。

锁库保护凭据，不是整个应用的登录锁。资产与对话仍可见，操作系统安全存储加密的模型 Key 也不由主密码派生。因此不要把未加密的本机资料视为密码保险箱。

## 网络边界

SSH、邮箱探测、WHOIS、TLS 和模型请求会连接填写的远程服务。用户问题、历史上下文和命中文档会发送到配置的模型。OAuth 只连接适配器指定的供应商端点，不接受渲染进程传入任意 Token URL，也不记录服务返回的令牌正文。

Markdown 不执行 HTML，不自动请求远程图片，不允许 `javascript:` 等外链协议。外部 HTTP/HTTPS 链接交给系统浏览器打开。

## 备份

1. 从托盘退出 Nanpad，确保文件写入已经结束。
2. 将完整数据目录复制到受保护的位置，备份文件包含个人元信息和加密凭据。
3. 单独妥善保管主密码。
4. 恢复前先备份当前目录。跨机器恢复后，操作系统加密的 API Key 可能无法解密，应重新录入；主密码库使用原密码解锁。

资产 JSON 导出不是完整备份，不包括主密码库、聊天记录和 AI 授权。分享问题报告前移除主机地址、账号、Key、Token、文档和对话内容。
