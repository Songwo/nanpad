# 司南 Nanpad 0.9.1

本版解决「插件不知道去哪下载」的问题：配对面板自带下载与安装引导。

- 「设置 → 浏览器插件」新增插件下载引导卡片：一键下载与本机版本配套的插件包（`releases/latest` 直链，桌面端与插件版本始终一致），附「解压 → 开发者模式 → 加载已解压的扩展程序」三步安装说明，并保留 GitHub 发布页入口作为回退。
- 插件本体无功能变化，仅版本号对齐。

## 验证记录

- `npm run typecheck`、`npm run i18n:check`、`npm run lint` 与 `npm test` 全部通过；lint 保留既有 9 条警告。
- 下载链接按 `AppInfo.version` 动态构造（本机 0.9.1 → `Nanpad-0.9.1-browser-extension.zip`），取不到版本或打开失败时回退到发布页；不涉及任何新权限或数据访问。
