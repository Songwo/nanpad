# 知屿 Zhiyu 1.3.0

本版新增 Chrome / Edge 密码双向迁移、同站多账号与浏览器登录助手，并将网页文档保存接入本机资料工作台。桌面与插件请一起更新至 1.3.0。

## 密码迁移与多账号

- 「密钥库 → 浏览器密码」提供导入、导出向导和浏览器操作指南。
- 读取浏览器官方 CSV，预览新增、重复、冲突与无效记录。确认后批量原子加密保存，预览不显示密码。
- 同站不同用户名分别保存，完全重复跳过；导入遇到同账号不同密码默认保留原记录并跳过。浏览器确认保存不同密码时保留为有名称区分的新版本。
- 兼容 BOM、引号、逗号、多行字段与空用户名；最多 10 MiB / 10000 条。取消或锁库撤销尚未提交的导入。
- 导出经过界面明文说明、系统确认和文件选择，只导出可迁移网站密码，便于导入 Chrome / Edge。

## 浏览器助手

- 自动发现可见登录表单，按当前精确站点列出账号，选择后填写，不自动提交登录。
- 正常登录采集后提示加密保存，确认一次直接入库；插件弹窗仍可重新读取与手动核对。
- 腾讯文档、微信公众号文章、飞书、语雀等自动提示文档保存，用户确认后保存已加载可见正文与来源。其他页面可在插件中主动保存。
- 同一来源不覆盖本机修改；不能读取的正文保存来源链接并说明结果。
- 登录采集、账号建议和文档提示可分别关闭。更新彩色品牌、按钮、状态提示与过渡。

## 安全与兼容

- 一次性短期选择凭据绑定扩展客户端和站点；后台验证真实标签页、顶层文档与导航代次，页面变化时拒绝填写。
- 锁库或撤销连接取消尚未提交的写入，不回传旧会话密码。密码不放进资产快照、文档、日志或问答索引。
- CSV 是明文文件，请仅用于浏览器密码迁移，导入结束后删除。插件不能批量直接读取浏览器原生密码库；不绕过系统认证。
- 网页文档为可见内容快照，不等同于在线原生文件完整下载或持续同步。自动填写不覆盖通行密钥、OAuth、隐藏表单、跨域框架与注册/改密场景。
- 延续 1.2.3 彩色图标和 Windows 任务栏修复，保持原 Nanpad 安装身份、数据目录与凭据兼容。

## 安装

下载同一 Release 的 `Nanpad-1.3.0-setup.exe`、`Nanpad-1.3.0-browser-extension.zip`，用 `SHA256SUMS.txt` 校验。桌面覆盖升级后，在浏览器扩展管理页替换并重新加载插件，刷新已有网页，再重新配对。安装包仍未做代码签名。

使用步骤见[浏览器助手教程](https://github.com/Songwo/nanpad/blob/main/docs/BROWSER-EXTENSION.md)，下载页会随正式发布同步版本与附件链接。
