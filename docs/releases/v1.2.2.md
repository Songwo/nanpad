# 知屿 Zhiyu 1.2.2

修复应用内 Logo 灰度显示及 Windows 升级后的快捷方式图标问题，保留 1.2.1 的全部功能和已有数据。

## 修复内容

- 标题栏、首次设置、AI 问答中的 Logo 统一使用深青色底、米白和浅玉色，浅深主题均保留品牌色。
- 安装升级时刷新已有桌面和开始菜单入口的程序目标、图标与应用身份，修复仅重命名快捷方式后仍保留旧目标的问题。
- 安装入口和任务栏重启信息统一使用 `resources/zhiyu.ico`，安装结束通知资源管理器刷新；不清空全局图标缓存，也不重启资源管理器。
- 发布流程新增真实打包程序检查，验证浅深主题 Logo 保持彩色，以及 Windows 能读取可执行文件中的彩色图标。

## 升级说明

下载 `Nanpad-1.2.2-setup.exe` 并安装到已有位置。内部应用 ID、`Nanpad` 数据目录及浏览器配对协议保持不变，升级不需要迁移资料。

手工创建并指向其他版本文件夹的快捷方式不会被安装程序批量改写；升级后请使用「知屿 Zhiyu」安装入口。开发运行时的 Electron 程序图标不代表正式安装包图标。

Windows 安装包当前未做代码签名。安装包、浏览器插件及 `SHA256SUMS.txt` 随本 Release 提供。

## 验证记录

- 类型检查、中英文字段检查、桌面打包和网页生产构建通过；全量 645 项测试通过，lint 0 错误、保留原有 19 条警告。
- 正式打包程序在隔离数据目录中完成浅深主题彩色 Logo、首次设置、重启、记录保存和四档缩放验证。
- Windows 原生接口读取的正式版图标通过品牌色检查，默认 Electron 图标被正确拒绝；发布工作流自动执行该检查。
- 本机执行从旧安装版到 1.2.2 的实际升级，确认桌面与开始菜单入口指向安装目录及独立品牌 ICO，桌面入口可启动新版。
- 开发与生产页面均完成桌面及 390px 手机检查，无控制台异常，生产内容与开发基线一致。未配置外部 PostgreSQL，构建按项目约定跳过迁移。
