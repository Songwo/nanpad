# 知屿 Zhiyu 1.2.0

司南从这一版起更名为 **知屿**：让文档、账号与数字资产形成可查询、可回溯的个人工作空间。新 Logo 以两片相连的岛形纸页为主体，统一应用、任务栏、安装程序与产品主页的展示。

## 文档与日常界面

- 文档默认进入阅读模式，需要修改时再展开编辑工具，减少长文档下的布局空白和干扰。
- 列表支持右键、Shift+F10 和更多菜单打开或删除文档。删除前显示具体标题确认；保存或删除失败时保留草稿与当前选择，关联资产不会被删除。
- 左侧导航可缩略，补充面板切换动画；统一下拉框、按钮、文件夹卡片及浅深主题，尊重系统减少动态效果偏好。
- 独立账号记录可保存用户名、密码、登录地址及备注，并关联已有文档或新建说明。凭据独立加密，删除凭据失败时保留记录方便重试。

## AI 问答与资料关联

- 右侧改为问答专用上下文：搜索历史、新对话、常用提问、引用来源和回到引用消息。手机上通过上下文面板访问。
- 消息区独立滚动，输入区保持在工作区底部，修复整页滚动后产生大片空白的问题。
- 新增 `search_documents`、`get_document` 和 `get_related_resources` 只读工具，支持查询文档、账号与资产之间的关联，并从来源打开对应资料。
- 默认仅允许工作区文档的标题、绑定和时间等元信息进入模型上下文。发送前勾选「本次允许检索文档正文」才允许该次请求发送有界正文片段；下一次自动重置，未经再次授权不回传之前标记为使用正文的回答。
- 文档正文不写入持久化 RAG/向量缓存；问答结果和引用仍保存在本机历史。已手动导入知识库的文件沿用原先的检索授权。模型工具不能读取密钥库、执行 SSH 或修改资产。

## 用量与活动

- 新增用量趋势、来源和模型构成图表与筛选，API Token、本机日志、流量与订阅额度分别统计。
- 本机监控支持 Codex、Claude Code、Grok Build、Gemini CLI 的支持格式日志，增量导入、事件去重、后台刷新及锁库暂停。
- 修复 Windows 包应用透明重定向缓存被误判为不安全路径的问题，保留有效缓存、历史记录及已有开关设置，**不需要管理员权限**。
- 增加每日活动查看，保留最近 90 天、最多 3000 条记录。

## 升级与边界

- 继续使用原应用 ID、`Nanpad` 数据目录、仓库地址及 `nanpad://` 协议。安装包名仍为 `Nanpad-1.2.0-setup.exe`，无需搬迁现有资料或重新配对浏览器插件。
- 本机日志监控只能读取客户端实际保存的用量；没有对应日志的网页会话、客户端或历史不能被还原成准确 Token。Grok 网页和 Grok Build 本机日志属于不同来源，使用过网页不代表本机有可读取日志。
- 账号凭据使用现有主密码库保护。文档、普通资产资料与问答历史是本机明文数据；正文授权不是自动脱敏，敏感内容请存入凭据字段。
- Windows 安装包当前未做代码签名。请使用本 Release 的安装包、浏览器插件包及 `SHA256SUMS.txt`。

完整历史见 [CHANGELOG.md](https://github.com/Songwo/nanpad/blob/main/CHANGELOG.md)，操作说明见 [使用教程](https://github.com/Songwo/nanpad/blob/main/docs/USER-GUIDE.md)。
