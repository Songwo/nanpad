# 司南产品介绍

司南面向维护多种数字资产的个人开发者、独立产品负责人和小型运维场景。主机、域名、证书和 AI 订阅不再分散在多个记录表中，可以按项目标签聚合，再通过关系图查看依赖。

也适合管理「我在哪个网站注册过账号，用的是哪个邮箱」这种日常问题。网站名称和标签负责帮助查找，登录网址、用户名和密码保存在本机加密库，注册邮箱通过资产关联记录。

## 日常场景

早上打开总览，检查离线资产和即将到期的项目。进入主机详情比较近期 CPU、内存与磁盘变化，需要操作时打开 SSH 终端。查看域名及证书关联，避免只续费域名却漏掉证书。为同一产品的主机、域名、邮箱和密钥打相同标签，在分组视图集中维护。

AI 订阅可以通过快速登录关联账号，按来源查看可读取的分类额度和重置时间。不同服务商公开给客户端的范围不同：Codex、Claude OAuth、Grok CLI、Gemini Code Assist 的额度不能统一视作网页订阅的完整权益。接口拒绝访问时显示错误，刷新失败时标明上次查询结果，方便判断数据是否仍可参考。

## AI 的职责

把运维手册导入本地知识库后，可以询问「哪些资产需要优先处理」「这个域名关联哪些主机」「本月 AI 订阅费用是多少」。模型根据当前记录与检索片段回答，引用来源可展开核对。

模型不是监控事实的来源，也不会自动替你执行修复。主机状态由实际探测产生，金额和日期以资产记录或服务商返回值为准。遇到风险操作，仍由用户通过原有界面执行。

查找密码时，模型返回的是资产详情的位置，不接触加密库中的密码。查询「有哪些邮箱分组」「某个分组有哪些账号」时，模型通过本地目录读取空组、未分组及账号归属。这些是司南的账号收纳组，与服务器上的收件箱、已发送等邮件文件夹不同。

需要检查收件箱时，由用户为本次提问开启实时查询；本机邮箱服务读取加密凭据完成 IMAP 认证，模型只收到数量和检查时间，不读取标题、正文或附件。查看本地分组无需实时查询许可，但分组名称和邮箱地址会作为元信息发送给配置的模型。

这不等于所有信息都不会联网：用户问题、近期历史、检索命中的公开资产字段和导入文档片段会发送给配置的模型服务。完整数据流及保护范围见 [安全与备份](SECURITY.md)。

## 本机工作方式

桌面端保留资料、资产、指标和对话，凭据单独加密。无账号云同步、团队权限和后台托管服务。首次设置的姓名用于本机身份展示，主密码用于打开加密凭据库。个人头像和资产图片可从本地文件上传、更换或移除，图片处理与保存也在本机完成。

## 0.6.0 的变化

邮件阅读器增加安全 HTML 与 Markdown / GFM 排版，标题、表格、引用和代码块不再统一挤成纯文本；仍可切换到解析后的原文。列表和阅读区分别显示加载骨架，选中与未读状态更清晰，窄窗口保留列表和正文的切换。

邮箱头像及所属分组可直接编辑，发件人支持本地自定义头像；没有图片时显示首字母，应用不自动向外部头像服务发送邮箱地址。正文远程图片默认拦截，用户可为当前邮件单独加载；图片服务器可能因此获知 IP 地址和阅读时间。随邮件携带且符合限制的 CID 图片在本机展示。

邮箱首页支持按分组名称搜索，真实 Agent 增加分组及账号目录查询，能够回答空组、未分组、账号归属等问题。密码、邮件正文、草稿和图片不进入这些工具结果。

已有文件夹收纳、批量移动、IMAP 搜索、未读筛选、附件下载、回复、转发和 SMTP 写信继续保留，草稿保存在主密码加密库。所有发信必须经过用户确认，正文不进入 Agent 或 RAG。连接条件及限制见 [邮箱工作台](MAIL-WORKSPACE.md)。

## 已有工作流

浏览器扩展可以发送当前站点到桌面端，经确认后填写账号、密码与注册邮箱。资产列表增加批量标签整理和统一关联，详情支持搜索多选，关系图支持手动连线。插件不读取网页密码或 Cookie，不承担自动填充；详见 [插件说明](BROWSER-EXTENSION.md)。

网站账号可以从粘贴的网址预填，选择密码类型后录入完整登录信息，并关联注册邮箱。凭据保存失败时保留表单，避免生成没有凭据却提示成功的记录。

邮箱增加手动检查和本次问答授权查询，区分总数、未读与新增数量。邮件数量提醒可以接入 Telegram、Server酱 / 微信及企业微信群机器人；默认关闭，桌面端运行且密钥库解锁时才工作，首次检查仅建立基线。推送内容不含邮箱地址或邮件内容。

已有 AI 分类额度、回调输入框、主题化下拉菜单、头像和资产图片继续保留。真实账号 HTTP 403 的上游限制没有因此消失，仍以服务商实际返回为准。本版不提供个人微信自动登录。详细操作和限制见 [使用教程](USER-GUIDE.md)。
