# 知屿 Zhiyu 1.7.0

修复本机用量达到 10 万条去重记录后停更、跨天筛选滞后及历史文件拖慢活跃采集的问题，同时将 Linux.do 接入改为知屿主身份登录。

## 用量自动更新与历史补采

- 原先缓存达到 100000 条事件指纹后仍显示监控开启，但会拒绝收录后续事件。新版保留原缓存备份，迁移为有界磁盘索引，让事件、汇总和读取位置在同一事务中保存。
- 旧版已推进读取位置、却未入账的日志会自动补采；保留全部已有去重指纹，避免历史统计重复相加。首次迁移后的补采分批进行。
- 优先读取近期变化文件和今天、昨天的日志目录，同时保留历史扫描配额。常规采集约每 10 秒运行，正文按增量读取，是否有新数据取决于客户端实际写入的日志。
- 图表和“今天”筛选在本地午夜自动更新；恢复窗口时补读已有统计快照，新的采集结果通过通知更新图表，不额外触发远程服务商请求。

Linux.do 现在用于登录和绑定知屿的主身份。首次打开或进入「个人资料」，通过系统浏览器授权，预览用户名、等级与平台返回的邮箱后确认绑定；普通用户不再需要配置 Client ID 或 Client Secret。

## 个人资料与本机工作区

- 从左侧头像菜单可直接打开个人资料，管理主身份、刷新资料、退出登录或更换账号。
- 昵称与头像分别提供同步选择，默认保留本机设置；关闭同步恢复本机资料。手动修改某一项只关闭该项同步，保存未改变的值不会关闭同步。
- 主身份凭据、头像与帖子缓存使用操作系统加密独立保存。锁定资产密钥库仍可管理主身份，首次设置仍需要创建或输入本地主密码。
- 退出登录清除本机登录凭据和帖子缓存，保留身份展示及已保存文档，不会退出其他设备。更换不同主身份需要明确确认。
- 密钥库移除普通「导入身份」入口，旧版已经导入的身份账号、密码、动态验证码和文档关联继续保留。

## 本人帖子

在个人资料的「我的帖子」中读取本人公开主题和回复，勾选后保存正文全文为文档。列表与正文复用缓存，逐条显示受限或失败原因并支持重试。主身份不伪装成密钥库账号，因此新文档不会产生指向不存在资产的关联；可在文档中继续提取账号并确认加密入库。

## 接入与验证

统一登录服务位于 `https://auth.allinsong.top`，通过既有 Cloudflare Tunnel 提供 HTTPS。应用密钥只放服务端；使用两层 PKCE、一次性交接码、精确本机回调校验及系统加密保存客户端登录凭据。

已验证公网健康检查与登录发起接口、官方授权地址和回调配置。自动化验证使用合成服务响应，覆盖拒绝授权、预览取消、资料同步、退出与改绑、无头像重启、真实系统加密、帖子导入及旧身份兼容。真实账号的授权和资料可用性还取决于用户在 Linux.do 完成授权及平台返回结果。

安装包、应用内更新信息、下载页和插件版本同步为 1.7.0；浏览器插件本版只同步版本号。
