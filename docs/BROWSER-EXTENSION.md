# 浏览器账号与文档助手

本文对应知屿 1.3.0。Chrome / Edge 插件自动发现登录表单、提示已保存账号，选择后填写；识别刚提交的账号，确认一次即可加密保存到桌面端。腾讯文档、微信公众号文章、飞书、语雀等页面会出现文档保存提示。扩展采用 Manifest V3，尚未上架扩展商店。

## 安装与配对

1. 从 [GitHub Releases](https://github.com/Songwo/nanpad/releases/latest) 下载同版桌面安装包和 `Nanpad-1.3.0-browser-extension.zip`。桌面「设置 → 浏览器插件」也有与本机版本对应的下载入口。
2. 安装并打开知屿，完成资料设置并解锁密钥库。插件 ZIP 解压到固定目录。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，启用开发者模式，选择「加载已解压的扩展程序」，指定包含 `manifest.json` 的目录。
4. 在知屿「设置 → 浏览器插件」生成并复制配对码，再打开浏览器工具栏的知屿插件，粘贴配对码并连接。主密码只在桌面端输入。
5. 已打开的网页刷新一次，让新版内容脚本生效。

升级时先更新桌面端，再替换原插件目录的文件并在扩展管理页重新加载；不要多套一层文件夹。重新加载、重启桌面端或锁库后需重新配对。64 位十六进制配对码单次使用，5 分钟有效；桌面「断开全部插件」可撤销连接。

## 从浏览器导入密码

Chrome 和 Edge 不提供扩展批量读写原生密码库的接口，因此迁移采用浏览器官方 CSV 功能。

1. 知屿「密钥库 → 浏览器密码 → 导入到知屿」选择 Chrome 或 Edge。
2. 复制向导的设置地址，在对应浏览器地址栏打开。Chrome 为 `chrome://password-manager/settings`；Edge 为 `edge://wallet/passwords`。不同版本可在设置中搜索「密码」，找到「导出密码」；系统可能要求 Windows 身份验证。
3. 浏览器导出 CSV 后，回到知屿选择文件。预览显示可导入、完全重复、密码冲突及无效项，表格不显示密码。
4. 确认导入。相同站点不同用户名分别保存；相同站点、用户名及密码重复时跳过；同账号密码不同的导入记录默认跳过，不覆盖已有密码。需要更新时，在账号详情核对并修改。
5. 成功后删除明文 CSV。新账号位于密钥工作台，可移动分组、关联文档与其他资产。

支持 Chrome / Edge 的 `name,url,username,password,note` 常用字段、UTF-8 BOM、带引号和换行的字段；单次最多 10 MiB、10000 条。无效网址与过长字段不截断后导入。预览 5 分钟有效，关闭窗口、取消或锁库会撤销尚未提交的预览。

## 导回 Chrome / Edge

在同一向导选择「导出到浏览器」，勾选明文说明，再通过系统确认和文件选择器导出 CSV。回到浏览器密码管理器的「导入密码」入口选择该文件，结束后删除 CSV。

导出包含具有有效网址、用户名字段和密码的账号记录；空用户名可迁移。没有网站密码的 API Key、SSH 密钥、OAuth 令牌和通行密钥不导出。文件准确保留密码字符，只用于密码管理器导入，不要用表格软件打开或分享。

## 自动建议与填写

进入已保存账号的网站登录页，知屿在页面角落提示可用账号。选择后填写可见登录框，仍由你检查并提交登录。也可打开插件，在「本站账号」选择。

同站多账号按用户名和名称展示；同账号不同密码有版本名称。匹配严格区分协议、域名和端口，不自动扩大到子域名。仅向 HTTPS 页面填写（本机开发页面除外），不向隐藏输入框、注册/改密表单、跨域 iframe、浏览器内部页、通行密钥或第三方 OAuth 流程填密码。页面跳转或账号选择过期时需重新选择。

## 保存刚登录的账号

「登录时自动采集」默认开启。提交密码表单后，插件提供「加密保存账号」提示；点击后直接加密保存到知屿，无需在桌面重复录入。同账号同密码返回已保存；不同密码保留旧记录并新增密码版本。也可在插件内重新读取可见表单，核对后点击「加密保存到知屿」。

待确认凭据仅存在扩展后台短期内存，最多保留 2 分钟；后台休眠、关闭标签页或撤销连接可能使其提前失效，需重新读取。离开原站点后不会在其他网站展示其账号。自动识别可能不适配部分自定义表单，插件提供手动核对入口。

只想记录网址时使用「仅记录站点并打开知屿」，此入口不带账号密码。旧版插件的桌面待确认队列继续兼容，建议桌面端与插件同步升级。

## 网页文档

在支持的网站看到「留一份文档到知屿」后点击「保存当前文档」；其他普通页面也可从插件主动保存。成功后在桌面「文档资产」找到快照，按需关联账号和资产。

保存范围是当前页面已加载且可读的正文和来源链接，不是在线文档原生文件的完整下载或持续同步。未加载分页、画布内容、登录限制、封闭 Shadow DOM 和跨域框架不会被绕过；无可读正文时保存来源链接并说明结果。脚本、表单、导航等不作为正文保存，正文只存文字，不执行网页 HTML。再次保存同一来源返回已有文档，保留本机编辑。

## 偏好与权限

插件可分别关闭登录采集、登录页账号建议和文档页提示；关闭某个自动提示不影响其他开关。提示右上角可关闭本页提示。

| 权限                     | 用途                                                           |
| ------------------------ | -------------------------------------------------------------- |
| `activeTab`、`scripting` | 用户打开插件时读取当前页可见表单                               |
| `tabs`                   | 核对目标页网址和导航状态，防止填入切换后的页面；不读取历史记录 |
| `storage`                | 会话区保存配对令牌，本机区保存开关偏好；不持久保存密码         |
| `http://127.0.0.1/*`     | 请求固定本机桌面服务 `127.0.0.1:47832`                         |
| 顶层网页内容脚本         | 发现表单与文档页、展示提示，并在确认后读取或填写               |

插件不读取浏览器 Cookie、历史记录或原生密码数据库。账号密码不进入 URL、日志、普通资产字段或问答索引。填入网站后，网站本身可以读取登录框内容，请先确认访问的是正确网站。

连接失败时检查桌面是否运行并解锁、插件与桌面是否同版、是否需重新配对。浏览器管理页和扩展商店页不能注入脚本，请切换普通网页使用。失败不会报告成功，可保持当前页面后重试。
