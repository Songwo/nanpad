# 浏览器快速保存

适用于司南 0.4.0 及以上版本。扩展采用 Manifest V3，可在 Chrome、Edge 中加载。当前提供可加载的扩展包，尚未上架扩展商店。

## 安装

1. 安装并启动对应版本的司南桌面端，使系统注册 `nanpad://` 打开方式。
2. 从同一 GitHub Release 下载 `Nanpad-0.4.0-browser-extension.zip` 并解压。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，启用开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 将司南扩展固定到工具栏。在普通网站打开插件，确认名称和站点地址，点击「保存到司南」。浏览器询问是否打开外部应用时选择司南。
5. 司南显示待确认网站。点击「填写账号并保存」，输入账号和密码，可选择已保存的注册邮箱。只有确认保存并解锁密钥库后才写入凭据。

## 工作范围

插件仅申请 `activeTab`，只有主动点击时才能读取当前网页地址与标题。没有常驻内容脚本、云端中转、密码抓取、Cookie 读取、浏览历史读取或自动填充。账号及密码在司南内填写，插件不接触主密码。

跨应用请求只传站点根地址和名称，移除用户名、密码、路径、查询参数和片段，避免携带 OAuth、密码重置等链接中的令牌。网站名称来自网页标题，发送前可修改。完整登录路径可在司南的加密账号字段中补充。

接收队列仅保存在内存中，最多 10 个不同站点，同一站点去重；退出软件清空队列。外部请求不会自动写入资产，也不会覆盖已打开的编辑表单。首次设置未完成时，会先等待用户完成设置。

## 排查

- 浏览器内部页面、本地文件和 `javascript:` 地址不支持保存。
- 点击后没有窗口：确认安装或启动的是 0.4.0 以上桌面端，检查浏览器是否阻止外部应用请求。
- 自编译或移动了便携目录：重新启动该目录下的桌面端以更新系统协议路径；保留原数据目录。
- 出现已存在的站点：可以忽略待确认请求，在已有资产中编辑。插件不会读取密钥库来推断账号是否重复。

## 开发与验证

`npm run extension:build` 将插件、共享链接校验模块和图标复制到 `release/v版本号/nanpad-browser-extension/`。手工加载时选择构建目录，不是源码目录。

先执行 `npm run desktop:build` 与 `npm run extension:build`，再执行 `node scripts/extension-integration.mjs`。它使用隔离 Electron 数据和 Chrome API fixture，检查插件弹窗、协议接收、加密账号保存、邮箱关联、批量标签、关系操作及窄窗口布局；不会读取真实浏览器会话或真人账号。
