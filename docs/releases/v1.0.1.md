# 司南 Nanpad 1.0.1

本版修复 Windows 任务栏重启图标和云端打包流程，包含 1.0 的全部更新。

这次更新把资产管理扩展为图文文档、节点与真实用量的工作空间，并修复日常操作中容易丢改动和误报的问题。

- 新增图文文档，可独立保存或关联多项资产；支持图片粘贴、拖拽、图床上传与失败重试。
- 新增自建节点管理、HY2 完整认证信息解析、机场与 3x-ui 流量记录。
- 新增支持的 API Token 用量历史、订阅额度快照，采集失败保留上次数据。
- 首页增加待处理分类入口；未填写的订阅月费不再显示为免费。
- 修复 SSH 二次错误弹窗，以及后台探测覆盖新导入节点、编辑和删除的问题。
- 探测请求去重、无变化时跳过重复写盘，默认启用硬件加速。
- 修复 Windows 窗口、托盘和安装图标；上线产品主页。

## 下载与升级

下载 `Nanpad-1.0.1-setup.exe`（Windows x64）。`SHA256SUMS.txt` 用于核对文件；此版本未做代码签名。升级前请备份原数据，使用原主密码解锁，不要删除本机 Nanpad 数据目录。

## 使用边界

- API 用量查询需要相应组织权限；订阅额度不等同于精确 Token 总量。
- 支持 `hy2://` 和 `hysteria2://`；旧版 HY1 暂不支持。TCP 检测不能验证 HY2 的 UDP 代理认证。
- 图床上传会将所选图片发送到配置的服务；请自行决定哪些图片适合上传。
- macOS / Linux 尚未提供经过验证的本版安装包。
