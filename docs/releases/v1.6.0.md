# 知屿 Zhiyu 1.6.0

把 Linux.do 本人帖子保存为文档，再从明确字段中提取账号并确认加密入库；新增网站动态验证码与在线服务资产，完善 Markdown 编辑、服务器采集设置和 WxPusher 提醒，同时统一仓库与下载品牌并修复 macOS 打包路径问题。

## 身份、本人帖子与账号资料

- 在「密钥库 → 导入身份」配置自己的 Linux.do Connect 应用，通过系统浏览器完成授权；核对资料后确认导入。同一身份重复导入更新原记录，保留本机命名和分组；邮箱与等级按平台返回值显示，不猜测缺失字段。
- 在身份详情读取本人的公开主题与回复，勾选后按需获取全文，保存为关联文档。列表与全文复用 15 分钟缓存，一次可选 1–20 条；导入保留标题、来源和正文，不覆盖已保存的本机文档。
- 正文优先使用平台返回的 Markdown，只有 HTML 时转为纯文本。读取失败单独列出，可重试；不会以摘要代替全文，不读取私信、受限帖子或浏览器 Cookie。
- 文档的「提取账号」在本机识别明确标签与 Markdown 表格，预览中可修改、勾选后确认保存。凭据进入加密密钥库，并关联来源文档；相同站点、用户名和密码复用已有记录，不同密码保留独立记录。
- 提取不删除原文中的账号密码；来源文档仍是普通本机资料，导出或授权 AI 读取前需检查敏感副本。锁库、预览过期或文档已修改时要求重新提取。

## 网站动态验证码与服务资产

- 账号详情增加「动态验证码」，支持 Base32 密钥和 `otpauth://totp` 链接，显示当前验证码、倒计时与复制操作。密钥加密保存，锁库后隐藏；支持 SHA1、SHA256、SHA512，6 位或 8 位验证码，不支持 HOTP 或短信接码。
- 新增「服务资产」，用于 Cloudflare Workers、个人博客、自建邮箱服务及其他在线服务。可记录网址、提供方、标签和手动状态，参与卡片、表格、关系图、文档绑定和 Agent 查询。
- 服务记录不会自动部署资源或执行探测；登录凭据另存密钥库，通过关联组成资料。

## Markdown、采集设置与邮件提醒

- 文档支持「Markdown 源码」「预览」和「富文本」。导入保留源码，GFM 表格、任务列表与代码块按格式显示，源码编辑自动保存并可原样导出。
- Markdown 转为富文本前说明可能变化的格式并要求确认，可以先导出留存或取消转换。原始 HTML 不执行，远程图片不自动下载。
- 「设置 → 监控采集」可选仅手动刷新或每 1、5、15、30、60 分钟采集服务器，默认 5 分钟。自动采集仅在窗口可见且密钥库解锁时进行；本机 AI 用量监控独立运行。
- 「设置 → 邮件推送」增加 WxPusher，使用用户自己的 AppToken 与 UID。继续只推送新增数量、相关邮箱未读数量和检查时间，不包含邮箱地址或邮件正文。
- 修复用量记录滚到底部后切换服务器等页面仍停在底部的问题。切换主页面回到顶部，当前页面更新数据时保留阅读位置，文档目录仍可独立定位。

## 品牌、打包与升级

- 仓库与下载页统一为 [Songwo/zhiyu](https://github.com/Songwo/zhiyu) 和 [知屿下载页](https://songwo.github.io/zhiyu/)。新安装包为 `Zhiyu-1.6.0-setup.exe`，配套插件为 `Zhiyu-1.6.0-browser-extension.zip`，包内目录为 `zhiyu-browser-extension`。
- 继续使用原安装身份与用户数据目录，避免品牌更名导致旧资料无法找到。可在应用内检查更新、下载并重启安装，或运行新版安装包覆盖升级；升级前可按[安全与备份](../SECURITY.md)保留完整副本。
- 修复 macOS 暂存目录的符号链接与 npm `--prefix` 路径解析不一致导致锁文件检查失败。暂存目录统一解析真实路径，安装依赖使用该目录作为工作目录，并校验锁定版本。
- 增加 Apple Silicon 与 Intel 的 macOS 打包检查工作流；产物是未签名测试程序，不等同于已签名、公证的正式发行版。步骤见 [macOS 构建说明](../MAC-BUILD.md)。

## 验证范围与限制

身份、帖子、推送和模型回归使用隔离资料与合成响应，不使用私人账户或向真实收件目标发送测试消息。Linux.do 的真实账号授权仍需用户配置自己的 Connect 应用，平台必须允许对应回调；论坛请求遭拒会显示实际错误，不能据协议测试宣称任意账号、全部帖子均可读取。

已通过类型检查、851 项自动化测试、国际化检查及网页与 Windows 安装包构建；ESLint 无错误，保留 19 条既有警告。开发版与生产网页在桌面和窄屏均通过渲染检查，正式桌面包通过身份、帖子全文、账号提取、TOTP、品牌图标和服务器采集回归。macOS 构建状态以对应 GitHub Actions 的实际结果为准。
